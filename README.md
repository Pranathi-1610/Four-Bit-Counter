# Four-Bit-Counter

# Project Objective
To design and simulate a 4-bit binary counter using Verilog HDL in Vivado.

# Project Files
- `counter_4bit.v` — Verilog source code for the 4-bit counter.
- `counter_4bit_tb.v` — Testbench used to generate the clock and test the counter.
- `waveform.png` — Simulation waveform showing the counter output.

# Working Principle
The counter increments its value on every rising edge of the clock. It counts from 0000 to 1111 and then returns to 0000.

# Simulation
Functional simulation was performed using Vivado Simulator. The waveform demonstrates the clock signal and the counter output.

# Tools Used
- Verilog HDL
- AMD Xilinx Vivado

# Result
The 4-bit counter was successfully simulated, and the expected counting sequence was observed in the waveform.
